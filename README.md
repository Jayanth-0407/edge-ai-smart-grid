# Smart Grid Digital Twin

Edge-AI enabled smart-grid digital twin for EV charging,
renewable integration, electricity-price forecasting,
grid-security analysis and adaptive energy management.

## Digital Twin

- SimBench 1-MVLV-urban-all-0-sw
- 10,458 buses
- 10,328 lines
- 135 transformers
- 11,542 loads
- 806 generators
- 15-minute annual profiles
- Pandapower AC power flow
